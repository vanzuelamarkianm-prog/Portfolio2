04 / PROBLEM-SOLVING

Think clearly.
Test step by step.

A practical approach to common development issues: inspect the problem, test one possible cause at a time, and record what you learn.

01 Website cannot connect to database ＋

Possible causes: MySQL service is stopped or connection details are incorrect.

Approach: Check service status, database name, credentials, host, and error logs.

Lesson: Verify configuration before changing unrelated code.

02 PHP page reports an undefined function ＋

Possible causes: Missing function definition, spelling error, or an include file that was not loaded.

Approach: Search for the function and inspect include paths and load order.

Lesson: Read the error carefully and isolate the smallest failing part.

03 Website works locally but not on hosting ＋

Possible causes: File paths, case-sensitive filenames, missing files, or hosting database settings.

Approach: Compare local and hosted configuration and inspect available error logs.

Lesson: Test the deployed version and document differences.

04 User cannot log in ＋

Possible causes: Validation errors, incorrect credentials, or an authentication/database issue.

Approach: Test valid and invalid inputs and review server-side validation without exposing passwords.

Lesson: Authentication must be tested securely, not just visually.

05 Excel results do not look correct ＋

Possible causes: Incorrect formula ranges, duplicate rows, or numbers stored as text.

Approach: Inspect data, verify formula ranges, and compare sample results manually.

Lesson: Clean data and independently verify important calculations.
